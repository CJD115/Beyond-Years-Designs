# Beyond Years Designs

## Stack
- React
- Vite
- JavaScript
- Tailwind/CSS
- React Router

## Design direction
- Premium independent UK studio
- Editorial rather than SaaS
- Cormorant Garamond + Inter
- Generous whitespace
- Strong typography
- Intentional asymmetry
- Restrained colour palette

## Avoid
- Generic SaaS layouts
- Excessive card grids
- Unnecessary gradients
- Glassmorphism
- AI-looking decorative elements
- Overuse of rounded containers

## Development principles
- Preserve existing design decisions unless asked to change them
- Prioritise accessibility
- Maintain responsive behaviour
- Don't introduce unnecessary dependencies
- Run build/lint after significant changes

## Important
Before making major visual changes, explain the proposed approach.
